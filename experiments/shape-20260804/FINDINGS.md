## 1. 형태 무관에는 범위가 있다 — v3 가설의 부분 반증

`DESIGN.md` §8 이 실험 A 의 반증 조건을 **"같은 곱 안에서 셀 간 차이가
2σ(2%)를 넘는다"** 로 적었다. 넘었다.

```text
곱 16 행 (W=16 고정, 변인은 nqp×ORD 분배뿐)
            1×16      2×8      4×4      8×2
 QP           30       60      120      240
 깊이         16        8        4        2
GET       12.766   12.813   12.691   11.956     ← -6.3%
MIX       10.634   10.741   10.645   10.105     ← -5.3%
SET        5.796    5.745    5.756    5.662     ← -1.8%
xfer      14.72    14.75    15.27    16.29      ← +7%
```

**깊이 16/8/4 에서는 QP 를 30 → 120 으로 4 배 늘려도 세 워크로드 전부 1%
안이다.** 형태가 무관하다. **깊이 2 에서 깨진다.**

정확한 진술은 **"형태 무관" 이 아니라 "깊이 4 이상에서 형태 무관"** 이다.

> 곱 하나만 돌렸으면 앞 세 점만 보고 "무관" 으로 끝냈을 것이다. 실험 A 를
> 곱 넷으로 늘린 것이 여기서 값을 했다 — 다만 나머지 세 곱을 못 돌려서
> **임계가 깊이의 절대값인지 곱 대비 비율인지는 아직 모른다.**

### 기전 — `xfer` 가 같이 오른 것이 지목한다

처리량만 떨어졌다면 서버측 경합을 의심했을 것이다. 그런데 **RDMA 왕복 자체가
14.72 → 16.29 µs 로 7% 늘었다.** QP 240 개에 깊이 2 씩이면 QP 당 큐잉이 거의
없어 HCA 가 QP 컨텍스트를 훨씬 자주 스위치한다.

**v2 의 "완료 1 건당 고정비" 해석을 수정한다.** v2 는 depth=1 천장을 고정비로
읽었는데, 여기서는 **깊이가 얕아질수록 그 비용이 커진다** — 고정이 아니라
깊이의 함수다. 실험 B 가 이 해석의 반증 시험이었는데 미시행이다.

## 2. SET 병목은 RDMA 밖이다 — 이번엔 능동적 증거다

같은 셀에서 워크로드별 하락 폭이 갈린다:

```text
xfer +7%  일 때    GET -6.3%    MIX -5.3%    SET -1.8%
SET 자신의 xfer 도 +4.1%(5.42 → 5.64 µs) 올랐는데 처리량은 1.8% 만 잃었다
```

**RDMA 를 실제로 느리게 만들었는데 SET 이 거의 반응하지 않는다.**

앞선 근거는 소극적이었다 — pipeline 6 배, QP 4 배, 깊이 1/4 로 축들을
움직여도 SET 이 5.6~5.8 M 에서 안 움직인다는 관찰. 이번은 **RDMA 경로를
직접 악화시킨 뒤에도 안 움직인다**는 능동적 증거다.

분해가 위치를 짚는다:

```text
A16-1 SET   span v3 7.84 µs   post 1,815.35 µs   → post/span = 232 배
```

SET 은 pac 이 스텁을 게시한 뒤 **WRITE CQE 를 기다려 `STORED` 를 보내는데**,
그 대기가 `ret`(0.64 µs)에 안 잡히고 전부 `post` 로 간다. 동시성을 아무리
만져도, RDMA 를 느리게 만들어도, 이 구간이 안 줄면 SET 처리량은 안 움직인다.

## 3. 계약이 재는 구간은 부하에 둔감하다

C1 스윕이 가장 선명하다:

```text
pipeline     1       8      32      64     384
span v3   17.88   26.42   23.51   23.76   22.12    ← 거의 불변
post      23.62   32.19   87.30   91.00  624.09    ← 26 배
```

**계약 지표(`span v3`)가 부하에 거의 반응하지 않고, 계약이 안 보는 구간
(`post`)이 부하를 다 받는다.**

이건 결함 주장이 아니다 — 계약은 "backend 진입 → 응용 가시" 를 재기로
정의됐고 그대로 재고 있다. 다만 **그 정의가 클라이언트 체감의 얼마를 덮는지**
는 이제 수치로 말할 수 있다: 운영점에서 **GET 0.9%, SET 1.6%**.

상세는 `md/LATENCY_BREAKDOWN.md`.

## 4. 이 캠페인에서 내가 틀린 것

기록해 둔다. 같은 형태가 반복됐다 — **데이터가 지지하는 것보다 강한 주장.**

| # | 주장 | 실제 | 잡아준 쪽 |
|---|---|---|---|
| 1 | `post` 는 깊이 무관 고정비 | 깊이 따라 23.6 → 624.1 µs | 다음 셀 측정 |
| 2 | Zipfian 이 L3 지역성으로 이득 | −8.5%. 부호가 반대 | 측정 |
| 3 | 혼합 Zipfian 은 재시도가 비용 | 재시도는 표지, 비용은 직렬화 | 산수(3 자릿수 안 맞음) |
| 4 | A16-3 이 깊이 단독 효과를 보인다 | `W` 도 같이 바뀜. 이중 변인 | **genie** |
| 5 | A16-1 예측 11.0~12.5 M | 12.766 M | 측정 |

**4 번이 가장 나쁘다** — 통제 실패를 결과로 발표했다. genie 가 잡았다.
이후로는 행 안 비교만 썼고, `A16-4` 의 -6.3% 는 곱·W 고정에 분배만 바뀐
통제된 비교다.

예측 규율의 효과: **실측에 앵커를 잡은 예측은 맞았고(A16-2), 추론으로 잡은
것은 빗나갔다(A16-1, Zipfian 2 회).**
